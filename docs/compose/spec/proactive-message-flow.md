# LucatBot 主动消息处理流程

> 设计目标：模拟真实用户在 QQ 中的行为模式——主动查看消息、选择会话、进入对话。
> 核心原则：**一次只看一个会话**，像真实人一样。

---

## 总体流程

```
启动
 │
 ▼
① 查看未读概况（工具）
 │  只看「哪个会话有消息」，不看内容，保留未读
 ▼
② 进入会话决策（Agent）
 │  输入：未读列表 + 机器人性格/心情/偏好
 │  输出：选中的单个会话（或空=暂不进入）
 ▼
③ 获取会话内容（工具）
 │  拉取该会话的完整消息，标记已读
 ▼
④ 理解并决策（Agent）
 │  分析消息内容，决定怎么回、回什么
 ▼
⑤ 执行动作（Agent/工具）
 │  回复消息 / 发表情 / 不回 / 其他操作
 ▼
⑥ 回到 ①，继续查看是否还有未读
```

---

## 详细步骤

### ① 查看未读概况（工具调用）

调用以下工具，**只获取会话标识，不获取内容**：

| 工具 | 输入 | 输出 | 说明 |
|------|------|------|------|
| `UnreadPrivateTool` | 无 | 有未读的私聊会话列表（用户QQ号+昵称+未读条数） | 保留未读状态 |
| `UnreadMentionTool` | 无 | 有人@我的消息所在会话列表（会话ID+@次数） | 保留未读状态 |
| `UnreadAtAllTool` | 无 | 有@全体成员消息的群列表（群号+群名+次数） | 保留未读状态 |

**关键约束**：
- 输出只有「谁」和「多少条」，**看不到完整内容**
- **保留未读状态**（不能标记为已读）
- 这是模拟人扫一眼消息列表的动作

### ② 进入会话决策（Agent 调用）

调用 `SessionPickerAgent`，由 LLM 决定接下来进入哪个会话。

**输入**（由调度器显式传递）：
- ①的输出：所有未读概况
- 机器人的**性格设定**（性格、说话风格、兴趣偏好）
- 当前**心情状态**（开心、疲惫、忙碌、无聊等）
- 当前**时间**（工作日/周末、白天/深夜）
- 其他可能影响决策的信息（如"特别关注的人"）

**输出**：
- **单个会话标识**（如 `private:123456789` 或 `group:987654321`）
- 或 **空**（表示：没感兴趣的，暂不进入任何会话）

**关键约束**：
- **必须返回单个会话**——真实用户不可能同时看两个会话
- 决策理由要自然："谁找我了？忙不忙？想不想聊？"

### ③ 获取会话内容（工具调用）

选定会话后，调用工具获取完整内容：

| 工具 | 输入 | 输出 | 说明 |
|------|------|------|------|
| `GetSessionContentTool` | 会话标识 | 最近N条消息（发送者+内容+时间） | 此时可标记已读 |

**关键约束**：
- 此时才能看到完整消息内容
- 拉取内容后标记已读（模拟人点进去看了）

### ④ 理解并决策（Agent 调用）

调用 `ReplyAgent`（或 `ResponsePlannerAgent`），分析消息并规划响应。

**输入**：
- ③获取的会话完整内容
- 机器人的性格/心情
- 会话历史（如有）

**输出**：决定要执行的动作，例如：
- 回复文本："哈哈是吗"
- 发送表情
- 不回复（已读不回）
- @某人
- 其他操作

### ⑤ 执行动作（Agent/工具调用）

根据 ④ 的决策执行具体操作：

| 操作 | 工具 | 说明 |
|------|------|------|
| 回复消息 | `SendMessageTool` | 发送文本到指定会话 |
| 发表情 | `SendEmojiTool` | 发送表情/表情包 |
| 不回复 | 无 | 静默结束 |

### ⑥ 循环

回到 ①，查看是否还有未读消息。如果没有了，则本轮结束（等待下一次触发）。

---

## 触发时机

| 触发方式 | 说明 |
|----------|------|
| 定时轮询 | 每隔 N 秒检查一次未读 |
| 新消息推送 | 收到新消息时触发（被动转主动） |
| 手动触发 | 管理员命令启动一轮 |

建议默认用**定时轮询 + 新消息推送**结合。

---

## 与现有架构的关系

```
MainPlugin（消息入口）
  │
  │  新消息到达 → 提供给 SessionPickerAgent 作为"有新消息"信号
  │
  ▼
AgentChain（调度循环）
  │
  ├─ Tool 层：UnreadPrivateTool / UnreadMentionTool / UnreadAtAllTool
  │           GetSessionContentTool / SendMessageTool / SendEmojiTool
  │
  ├─ Agent 层：SessionPickerAgent（选会话）
  │            ReplyAgent（理解+规划响应）
  │
  └─ 机器人的「人格状态」：性格、心情、时间感知
       （存放在 Session / 机器人状态中，每次调度时显式传入）
```

## 新增组件清单

### 工具（Tool）

| 类名 | 状态 | 职责 |
|------|------|------|
| `UnreadPrivateTool` | 新增 | 查看未读私聊会话列表（不看内容） |
| `UnreadMentionTool` | 新增 | 查看@我的消息所在会话列表 |
| `UnreadAtAllTool` | 新增 | 查看@全体的群列表 |
| `GetSessionContentTool` | 新增 | 获取指定会话完整内容 |
| `SendMessageTool` | 新增 | 向会话发送消息 |
| `SendEmojiTool` | 新增 | 发送表情/表情包 |

### Agent

| 类名 | 状态 | 职责 |
|------|------|------|
| `SessionPickerAgent` | 新增 | 根据未读概况+人格状态，选一个会话进入（或不进） |
| `ReplyAgent` | 已有 | 根据消息内容生成回复 |
| `EchoAgent` | 已有 | 测试用 |

### 机器人人格状态

| 组件 | 说明 |
|------|------|
| `BotPersona` | 性格设定、说话风格、兴趣偏好 |
| `BotMood` | 当前心情（可变） |
| 时间感知 | 工作日/周末、白天/深夜 |

## 关键设计原则

1. **一次一个会话**——模拟真实用户，不能同时处理多个对话
2. **先看概况再看内容**——扫一眼列表 → 选一个 → 点进去，像人一样
3. **保留未读**——在做出进入决策前，不消耗未读状态
4. **人格驱动决策**——选哪个会话、怎么回，都受性格/心情影响
5. **循环处理**——处理完一个会话后回到概况检查，直到没有未读
